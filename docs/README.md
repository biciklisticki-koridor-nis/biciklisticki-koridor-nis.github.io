# docs/

Materijali koji ne idu na sajt: uputstva za terenski rad, protokoli merenja i
prateće skripte.

Sajt prikazuje *rezultate*. Ovde stoji ono što treba **pre** rezultata — kako
se podaci prikupljaju, kojim redom, čime i sa kojim ograničenjima. Tehnička
obrazloženja već objavljenih analiza su u [tehničkom dnevniku](../dnevnik.html).

Direktorijumi se imenuju po analizi kojoj pripadaju, kao i stranice na sajtu.
